# تطبيق تقييم المخيمات والبلاغات (PWA)

تطبيق ويب تقدّمي (PWA) لإدارة تقييمات المخيمات والبلاغات الميدانية، بواجهة عربية (RTL)
وصلاحيتين: **المشرف** و**المدير**.

## المزايا

### 👷 المشرف (Supervisor)
- تسجيل حساب خاص به (Sign up).
- **تقييم المخيم**: نموذج يعرض بنود التقييم، لكل بند:
  - تحديد الحالة **متوفر / غير متوفر** (إلزامي).
  - **إرفاق ملف إلزامي** لكل بند (صورة أو PDF).
  - ملاحظة اختيارية.
- **رفع البلاغات**: تسجيل أعطال أو ملاحظات (مثال: عطل كهرباء) بعنوان وتصنيف ووصف ومرفق اختياري.
- **سجل التقييمات** و**سجل البلاغات** الخاصة به.

### 🧑‍💼 المدير (Manager)
- **لوحة تحكم**: إحصائيات لكل التقييمات والبلاغات، توزيع البلاغات حسب التصنيف، ونِسب توفّر البنود.
- عرض **جميع** التقييمات والبلاغات من كل المشرفين.
- **إغلاق البلاغ ووضعه "تمّت"** (وإعادة فتحه عند الحاجة).
- **إدارة بنود التقييم**: إضافة / تعديل / تفعيل / تعطيل / حذف البنود التي تظهر للمشرف.

### 📱 PWA
- قابل للتثبيت على الجوال (manifest + أيقونات).
- Service Worker للعمل دون اتصال (قشرة التطبيق) مع مرور طلبات الـ API عبر الشبكة.

## التقنيات
- **الخلفية**: Node.js + Express + SQLite (better-sqlite3).
- **المصادقة**: JWT + كلمات مرور مُجزّأة (bcrypt).
- **المرفقات**: رفع عبر multer (صور / PDF، بحد أقصى 15MB لكل ملف).
- **الواجهة**: HTML/CSS/JavaScript خام (بدون أطر)، تصميم RTL متجاوب.

## التشغيل محلياً

```bash
npm install
npm run icons     # توليد أيقونات PWA (مرة واحدة)
npm start         # يشغّل الخادم على http://localhost:3000
```

عند أول تشغيل يُنشأ حساب مدير افتراضي وتُزرع بنود التقييم الأساسية.

### حساب المدير الافتراضي
| الحقل | القيمة |
|-------|--------|
| اسم المستخدم | `manager` |
| كلمة المرور | `manager123` |

> غيّرها عبر متغيّرات البيئة `MANAGER_USERNAME` و`MANAGER_PASSWORD` قبل أول تشغيل،
> أو من قاعدة البيانات لاحقاً. في الإنتاج، عيّن `JWT_SECRET` بقيمة عشوائية طويلة.

المشرفون يسجّلون حساباتهم بأنفسهم من شاشة الدخول ("حساب مشرف جديد").

## الإعدادات (متغيّرات البيئة)
انسخ `.env.example` إلى `.env` وعدّل حسب حاجتك (يمكن أيضاً تمريرها مباشرة عند التشغيل):

| المتغيّر | الافتراضي | الوصف |
|----------|-----------|-------|
| `PORT` | `3000` | منفذ الخادم |
| `JWT_SECRET` | `dev-secret-change-me` | سرّ توقيع الجلسات — **غيّره في الإنتاج** |
| `TOKEN_TTL` | `30d` | مدة صلاحية الجلسة |
| `MANAGER_USERNAME` / `MANAGER_PASSWORD` | `manager` / `manager123` | حساب المدير الأول |
| `DATA_DIR` / `UPLOAD_DIR` | `./data` / `./uploads` | مسارات التخزين |

## واجهات الـ API (مختصر)
| الطريقة | المسار | الصلاحية | الوصف |
|---------|--------|----------|-------|
| POST | `/api/auth/register` | عام | تسجيل مشرف |
| POST | `/api/auth/login` | عام | تسجيل الدخول |
| GET | `/api/criteria` | مسجّل | البنود الفعّالة |
| POST/PUT/DELETE | `/api/criteria/:id?` | مدير | إدارة البنود |
| POST | `/api/assessments` | مشرف | إنشاء تقييم (مع مرفق لكل بند) |
| GET | `/api/assessments` | مسجّل | مشرف: تقييماته، مدير: الكل |
| POST | `/api/reports` | مشرف | رفع بلاغ |
| GET | `/api/reports?status=` | مسجّل | مشرف: بلاغاته، مدير: الكل |
| PUT | `/api/reports/:id/close` | مدير | وضع البلاغ "تمّت" |
| PUT | `/api/reports/:id/reopen` | مدير | إعادة فتح البلاغ |
| GET | `/api/stats` | مدير | إحصائيات اللوحة |
| GET | `/api/attachments/:id` | مسجّل | عرض/تحميل مرفق |

## هيكل المشروع
```
server/            خادم Express
  index.js         نقطة التشغيل + خدمة الملفات الثابتة
  db.js            قاعدة البيانات + المخطط + البيانات الأولية
  auth.js          JWT ووسائط الصلاحيات
  upload.js        إعداد رفع الملفات
  routes/          مسارات الـ API
public/            واجهة الـ PWA
  index.html, app.js, styles.css
  manifest.json, service-worker.js, icons/
scripts/
  generate-icons.js  مولّد أيقونات PNG (بدون اعتماديات)
```

> ملاحظة: مجلّدا `data/` (قاعدة البيانات) و`uploads/` (المرفقات) يُنشآن تلقائياً عند التشغيل
> وهما مستثنيان من Git.
